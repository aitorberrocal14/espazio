# Decisiones

Una decisión por archivo, nombrada `AAAA-MM-DD-titulo-corto.md`.

Estructura mínima: problema, decisión, alternativas descartadas y por qué,
criterios de aceptación verificables, qué queda fuera, riesgos y coste de
revertir.

Existe para que la misma discusión no se repita en tres semanas. Si una
decisión se revierte, no se borra el archivo: se añade el motivo y se enlaza
la que la sustituye.
